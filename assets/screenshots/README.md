# Screenshots

Drop the app screenshots referenced by the main [`README.md`](../../README.md) here.

Expected filenames (PNG, ideally a phone-sized portrait, ~1080px wide):

| File | Suggested content |
|---|---|
| `dashboard.png` | Home screen with a few limits configured |
| `add-limit.png` | The screen where you add an app and set its quota |
| `nuclear.png` | Nuclear Mode setup / active state |

You can use any number of images — just keep the filenames in sync with the
`<img>` tags in the root `README.md`.

> ⚠️ Review each screenshot for personal data (visible apps, contacts,
> notifications) before committing — this folder is published publicly.
